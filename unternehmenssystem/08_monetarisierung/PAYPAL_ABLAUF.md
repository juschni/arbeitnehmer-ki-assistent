# PayPal-Ablauf – CareerAI (Anfänger-Anleitung)

**Stand:** 2026-09-25  
**Ziel:** 19 € Karriere-Boost verkaufen und Zugang freischalten

---

## 1. PayPal Business-Konto anlegen

1. Gehe auf https://www.paypal.com
2. Klicke auf „Geschäftskonto eröffnen“ (oder „Anmelden“ → Geschäftskonto)
3. Mit deinen echten Daten registrieren
4. E-Mail bestätigen
5. Optional: Gewerbe später nachtragen (unter Einstellungen → Geschäftsinformationen)

Das reicht für den Start.

---

## 2. PayPal-Button erstellen (19 €)

1. Einloggen → oben rechts auf dein Konto → **Zahlungen empfangen**
2. **PayPal-Buttons** → **Button erstellen**
3. Einstellungen:

   - **Button-Typ:** „Kaufen Sie jetzt“
   - **Artikelname:** Karriere-Boost – CareerAI
   - **Preis:** 19,00
   - **Währung:** EUR
   - **Versand:** 0,00 (digitales Produkt)
   - **Steuer:** 0,00 (bei Kleinunternehmerregelung)

4. Unter „Erweiterte Einstellungen“:
   - **Erfolgs-URL (Return URL):** https://juschni.github.io/arbeitnehmer-ki-assistent/danke.html
   - **Abbruch-URL:** https://juschni.github.io/arbeitnehmer-ki-assistent/

5. Button generieren → Code kopieren

---

## 3. Zugangscode-System (einfach & robust)

### Variante zum Start (empfohlen)

- Du legst eine Liste mit Codes an (z. B. in Google Sheets oder einer Textdatei)
- Beispiel-Codes: CA-19-7K2M, CA-19-9P4Q, CA-19-3X8R …
- Nach jeder Zahlung:
  1. PayPal benachrichtigt dich per E-Mail
  2. Du schickst dem Käufer eine E-Mail mit einem unbenutzten Code + Link
  3. Du markierst den Code als „verwendet“

### Später automatisieren

Mit Zapier oder Make.com:
PayPal-Zahlung → automatische E-Mail mit nächstem Code aus der Liste
